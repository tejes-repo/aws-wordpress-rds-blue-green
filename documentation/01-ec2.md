# EC2 Instance Launch and Configuration

## 1. Open Amazon EC2

1. Sign in to the AWS Management Console.
2. Open **EC2** service.
3. Select the required AWS Region.
4. Click **Launch Instance**.

## 2. Configure Instance Name

In the **Name and tags** section:

* Enter a name for the EC2 instance.

Example:

```text
WordPress-EC2
```

## 3. Select Amazon Machine Image (AMI)

In the **Application and OS Images (Amazon Machine Image)** section:

* Select **Amazon Linux**
* Use **Amazon Linux 2023**

This AMI is used as the operating system for the WordPress application server.

## 4. Select Instance Type

In the **Instance type** section:

* Select the instance type required for the project.
* For a Free Tier practice environment, select an instance type that is currently eligible for the applicable AWS Free Tier offer.

> Free Tier eligibility can depend on the AWS account and the current AWS Free Tier offer. Check the current eligibility before launching.

## 5. Configure Key Pair

In the **Key pair** section:

* Select an existing Key Pair or create a new Key Pair.
* Download the key pair if creating a new one.
* Keep the private key secure.

The Key Pair is used to securely connect to the Linux EC2 instance.

## 6. Configure Network Settings

In the **Network settings** section:

### VPC

* Select the required **VPC**.
* In this project, the existing/default VPC was selected.

### Security Group

* Select the existing/default **Security Group**.

The project uses the selected Security Group for the EC2 instance.

### Other Network Configuration

The remaining network configuration was kept at the default settings for this project.

## 7. Configure Storage

In the **Configure storage** section:

* Keep the default storage configuration.

No additional storage configuration was required for this EC2 launch.

## 8. Review Configuration

Before launching, verify:


AMI          → Amazon Linux 2023
Instance     → Selected required instance type
Key Pair     → Selected Key Pair
VPC          → Selected VPC
Security SG  → Default/selected Security Group
Storage      → Default
Other        → Default
```

## 9. Launch Instance

Click:

**Launch Instance**

AWS will create the EC2 instance using the selected configuration.

## 10. Verify EC2 Instance

After launching:

1. Go to **EC2 → Instances**.
2. Find the newly created instance.
3. Check the instance state.
4. Wait until the instance reaches:

```text
Running
```

5. Verify that the **Status check** is successful.

## 11. EC2 Role in This Project

The EC2 instance is used as the **WordPress application server**.

The application architecture is:


Amazon Linux 2023
        ↓
      Apache
        ↓
       PHP
        ↓
    WordPress
        ↓
Amazon RDS MySQL
```

## 12. Result

The Amazon Linux 2023 EC2 instance was successfully launched using the selected VPC and default Security Group, while the remaining configuration was kept at the default settings.
